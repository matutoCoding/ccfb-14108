# 跳水动作分析系统

浏览器端跳水动捕分析工具,TypeScript + three.js 实现,**所有数据存本地浏览器**(IndexedDB + localStorage),无后端、无网络上传。

## 启动

```bash
npm install
npm run dev        # 开发,默认 http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run verify     # 核心数学验证(33 项,含圈数硬指标)
npx tsx scripts/e2e.ts   # 端到端业务流冒烟
```

首次打开会自动生成演示数据:2 名队员、2 个训练课、107B/205C/5253B 共 9 跳,其中 107B 第 3 跳掺了丢帧与关节翻转。
控制台执行 `diveApp.resetDemoData()` 可重置。

## 六个页面

| 页面 | 功能 |
| --- | --- |
| 队员档案 | 身高/臂展/体重,蒙皮人体按这些尺寸缩放 |
| 动作库 | 按 FINA 代码(107B/5253B…)归档,自动解析翻腾/转体周数,挂难度系数 DD |
| 训练课 | 按日期串起每一跳;BVH/CSV 导入,自动识别离板/入水,缺陷标黄并补插值 |
| 三维回放 | 0.1x 慢放/逐帧、锁重心/裁判席/水下相机、关键帧、实时圈数、标注、分析单导出 |
| 对比分析 | 两跳按离板帧对齐,一实一虚叠加或左右分屏,自动跳到关节角差异最大段 |
| 设置 | 关节角度阈值、采样率、水面高度、残影参数、多厂商骨骼命名映射 |

## 关键设计

### 圈数统计为什么准
生成器与分析器共用同一套旋转分解约定 `Qp = Qyaw · Qtw(γ) · Qsom(β)`:

- **翻腾**:骨盆纵轴投影到翻腾平面(世界 YZ),逐帧极角差累加
- **转体**:剔除 yaw 与翻腾后,解析出绕体纵轴的扭转角 γ 再解包裹

分析器是生成器的严格逆运算,因此 107B 必然还原为 3.5 周翻腾、0 周转体;5253B 为 2.5 周 + 1.5 周。验证脚本对多种子取数据,误差 < 0.03 周。

### 离板对齐
导入片段自动检测:板高窗口内垂直速度峰值帧 = 离板;髋点下穿水面+髋高线 = 入水。时间轴上离板(绿)/入水(红)标记可直接拖动修正,改后最高点与打开帧自动重算。对比页公共时间轴第 0 帧对齐两跳各自离板瞬间。

### 数据缺陷
- 丢帧:NaN 空洞检测,根位置线性插值、关节旋转球面插值(slerp)
- 关节翻转:相邻帧四元数点积 < 0 检测反号,校正后边界再 slerp 平滑
- 修复区间在时间轴标黄,记录保留

### 防糖纸效应
前臂/大腿等关节做 Swing-Twist 分解,扭转分量超过生理极限(前臂 85°、大腿 45°)被钳制,只保留摆动分量驱动肢体。

### BVH 兼容
导出/自有 BVH 使用四元数通道(Qx Qy Qz Qw)避免欧拉万向锁;导入时同时支持标准 `*rotation` 欧拉通道,按通道顺序相乘。厂商骨骼名在设置页手动映射一次后按厂商名持久化,之后自动套用。

## 目录结构

```
src/core/   纯逻辑层(无 three.js 依赖,可在 Node 直接验证)
  math3d.ts      向量/四元数/Swing-Twist
  generator.ts   跳水动作动捕生成
  analysis.ts    FK、圈数累计、关节角、入水指标、事件识别
  repair.ts      丢帧/翻转检测修复
  bvh.ts/csv.ts  数据格式
  storage.ts     IndexedDB/localStorage
src/three/  three.js 渲染层(figure 蒙皮人体、venue 场馆、scene 回放、compareScene 对比)
src/ui/     页面与组件
scripts/    verify.ts(33 项指标)、e2e.ts(业务流冒烟)
```
